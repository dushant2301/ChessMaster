# ChessMaster

A fully functional chess web application built using HTML, CSS, and JavaScript that allows players to enjoy a complete chess experience directly in their browser.

## 🌐 Live Demo

**Play now:** [https://chessmaster-dushant.netlify.app](https://chessmaster-dushant.netlify.app)

## 🚀 Deploy Your Own

Deploy your own copy of ChessMaster to Netlify with one click:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/dushant2301/ChessMaster)

## ✨ Features

- Complete chess game with all official rules
- Castling, en passant, and pawn promotion
- Play vs AI or 2-player local mode
- Chess puzzles
- Multiple board themes and settings
- Move history and game analysis
- Timer support with multiple time controls

## 🛠️ Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/dushant2301/ChessMaster.git
   ```
2. Open `index.html` in your browser, or use a local server:
   ```bash
   npx serve .
   ```

## 📦 Deployment on Netlify

1. Push this repository to GitHub
2. Log in to [Netlify](https://www.netlify.com/)
3. Click **"Add new site"** → **"Import an existing project"**
4. Connect your GitHub account and select the **ChessMaster** repository
5. Set the **Publish directory** to `.` (root)
6. Click **Deploy site**

The `netlify.toml` file in this repository is already configured for deployment — no build step is needed since this is a static site.
